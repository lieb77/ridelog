# ridelog

In 2004, they year I got serious about bicycle riding, I created a ride log to track my mileage and to document each ride. My first ridelog was a CGI app written in Perl using MySQL as a backend. At some point I rewrote it in PHP but still as a standalone app.
Then in 2010 I rewrote it as a Drupal module, initially in Drupal 6, but soon upgraded to Drupal 7.
This iteration is a complete rewrite for Drupal 8,9,10 and hopefully onward.
